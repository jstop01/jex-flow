## 2. ProcessNode API 서비스 분리

ProcessNode의 서비스 타입 API 로직을 별도 서비스 레이어로 분리

### 신규 파일:

1. **src/types/process.ts**
   - ServiceTypeOption 인터페이스 정의
   - ServiceTypeDataResponse 인터페이스 정의

2. **src/data/process-mock.ts**
   - MOCK_SERVICE_TYPE_DATA: 개발용 목 데이터
   - 서비스 타입 목록 (기본 프로세스, HTTP 서비스, 데이터베이스, 파일 처리, 큐 처리, 스케줄러)

3. **src/services/processService.ts**
   - fetchServiceTypes(): 서버에서 서비스 타입 목록 조회
   - syncServiceTypes(): 서버와 서비스 타입 데이터 동기화
   - USE_MOCK 플래그로 목 모드/실제 API 모드 전환

### 수정된 파일:

4. **src/components/ProcessNode.tsx**
   - 인라인 ServiceTypeOption 인터페이스 제거
   - '../types/process'에서 ServiceTypeOption import
   - '../services/processService'에서 fetchServiceTypes import
   - useEffect 내 인라인 API 호출을 서비스 함수 호출로 변경
