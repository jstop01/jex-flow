## 2. MultiConcat 필드 선택에서 Record 타입 처리 개선

Record 타입은 직접 선택 불가하고, Record 내부 필드만 선택 가능하도록 수정

### 수정된 파일:

**src/components/MappingEditorModal.tsx**

1. 신규 함수 추가: `flattenFieldsForSelection`
   - Record 내부 필드를 재귀적으로 평탄화
   - Record 자체는 `isSelectable: false`로 표시
   - 일반 필드는 `isSelectable: true`로 표시
   - `fullPath` 속성으로 전체 경로 저장 (예: "REC.field1")

2. 소스 필드 드롭다운 수정:
   - `flattenFieldsForSelection(node.outputs)` 사용
   - Record는 보라색 헤더로 표시 (선택 불가)
   - Record 내부 필드는 들여쓰기로 표시 (선택 가능)
   - 필드 추가 시 `fullPath` 사용

3. 타겟 필드 드롭다운 수정:
   - `flattenFieldsForSelection(node.inputs)` 사용
   - 소스와 동일한 UI 패턴 적용

### UI 변경사항:

**기존:**
```
소스 필드 선택...
├─ Node1 (Process)
│  + REC         <- Record도 선택 가능했음
│  + Field1
```

**변경 후:**
```
소스 필드 선택...
├─ Node1 (Process)
│  ▼ REC (Record)     <- 보라색 헤더, 선택 불가
│    + field1         <- Record 내부 필드, 선택 가능
│    + field2
│  + Field1           <- 일반 필드, 선택 가능
```
