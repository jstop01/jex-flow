### 수정된 파일:
1. **src/components/ContainerFlowModal.tsx**

   - `mappingEditorModal` 상태 추가 (isOpen, nodeId, mappings)
   - `openNodeEditor` 함수를 initialization useEffect 이전으로 이동
   - `openNodeEditor`에 Mapping 노드 처리 로직 추가

### 변경 이유:

- `openNodeEditor`를 useEffect 이전에 정의하여 closure 문제 해결
- 새로 추가되는 노드에도 `onEdit` 콜백이 주입되도록 수정

### 수정된 노드 타입별 동작:
| 노드 타입 | 버튼 | 클릭 시 동작 |

| Mapping | Edit Mapping | MappingEditorModal 열기 |

| For/ForEach/While | Expand | 중첩 ContainerFlowModal 열기 |

### 변경 이유:
- 사용자 요청에 따라 모든 더블클릭 이벤트 삭제
- 버튼이 작동하지 않던 문제는 `openNodeEditor`의 stale closure 문제
- `nodesRef`를 사용하여 항상 최신 nodes 상태 참조

### 코드 변경 상세:

**nodesRef 추가 (stale closure 해결):**
```typescript
// Ref to always have access to latest nodes
const nodesRef = useRef(nodes);
useEffect(() => {
  nodesRef.current = nodes;
}, [nodes]);

const openNodeEditor = useCallback((nodeId: string) => {
  const node = nodesRef.current.find(n => n.id === nodeId);  // nodes 대신 nodesRef.current 사용
  if (!node) return;
  // ...
}, []); // dependency에서 nodes 제거
```
