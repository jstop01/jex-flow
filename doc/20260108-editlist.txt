## 3. Edge Snapping 유효성 검증 강화

### 문제점:
- 노드를 연결선(Edge) 위에 드롭하면 자동으로 연결이 분할되는 기능(Edge Snapping)이 있음
- 하지만 `isValidConnection`의 연결 규칙을 따르지 않아 일관성이 없었음
- 안 되어야 하는 연결이 생기거나, 되어야 하는 연결이 안 되는 문제 발생

### 수정된 파일:
1. **src/App.tsx** (라인 548-787)
   - Edge snapping 제외 노드 타입 추가:
     - `variable` 노드 (연결 불가 노드)
     - `isStart` / `isEnd` 노드 (특수 노드)
   - Container 경계 검증 추가:
     - 드래그한 노드와 edge의 source/target이 같은 컨테이너에 있어야 함
     - `parentId` 비교로 검증
   - 중복 연결 검증 추가:
     - source 핸들당 1개 연결만 허용 (기존 edge 제외하고 검사)
     - target 핸들당 1개 연결만 허용 (End 노드는 다중 허용)

2. **src/components/ContainerFlowModal.tsx** (라인 724-834)
   - Edge snapping 제외 노드 타입 추가:
     - `variable` 노드
     - `isStart` / `isEnd` 노드
   - 중복 연결 검증 추가 (App.tsx와 동일)

### 수정 후 동작:
| 노드 타입 | Edge Snapping |
|----------|---------------|
| Variable | X (제외) |
| Start/End | X (제외) |
| 일반 노드 | O (검증 후 허용) |

### 검증 규칙:
1. 같은 컨테이너(parentId) 내에서만 edge snapping 가능
2. source 핸들에 이미 다른 연결이 있으면 edge snapping 불가
3. target 핸들에 이미 연결이 있으면 edge snapping 불가 (End 노드 제외)

### 요구사항:
- Record는 Record끼리만 매핑 가능
- Field는 Field끼리만 매핑 가능
- 타입이 다른 필드 간 매핑 시도 시 자동 차단

### 수정된 파일:
1. **src/components/MappingEditorModal.tsx**
   - `handleDragStart` 함수 수정:
     - `isRecord` 파라미터 추가
     - `sourceIsRecord` 데이터를 drag event에 추가
   - `handleDrop` 함수 수정:
     - `targetIsRecord` 파라미터 추가
     - Source와 Target의 `isRecord` 값 비교
     - 타입 불일치 시 매핑 생성 차단 및 경고 로그 출력
   - Source OUTPUT 렌더링:
     - Record 필드도 드래그 가능하도록 변경 (`draggable={true}`)
     - `handleDragStart`에 `field.isRecord` 전달
     - 커서 스타일 통일 (`cursor: 'grab'`)
   - Target INPUT 렌더링:
     - Record 필드도 드롭 가능하도록 변경
     - `handleDrop`에 `field.isRecord` 전달

### 동작 방식:
```
Source OUTPUT          Target INPUT
─────────────          ────────────
Record1      ──────→   Record2     ✓ (Record ↔ Record)
  └ Field1   ──────→     └ Field2  ✓ (Field ↔ Field)
  └ Field1   ──X───→   Record2     ✗ (Field → Record 차단)
Record1      ──X───→     └ Field2  ✗ (Record → Field 차단)
```

### 검증 로직:
```javascript
// handleDrop 내부
if (sourceIsRecord !== targetIsRecord) {
  console.warn('Type mismatch: Record can only map to Record, Field can only map to Field');
  return; // 매핑 생성 차단
}
```
