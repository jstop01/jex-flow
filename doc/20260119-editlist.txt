## 9. 다중 소스 → 단일 타겟 매핑 (Concat) 기능

여러 소스 필드를 하나의 타겟 필드에 연결하여 값을 연결(Concat)하는 기능

### JSON 데이터 구조 변경:

**기존 구조:**
```json
{
  "id": "map1",
  "sourceNodeId": "start",
  "sourceFieldName": "userId",
  "sourceFieldIndex": 0,
  "targetNodeId": "process1",
  "targetFieldName": "reqUserId"
}
```

**새로운 구조 (sources 배열):**
```json
{
  "id": "map1",
  "sources": [
    { "nodeId": "start", "fieldName": "userId", "fieldIndex": 0 },
    { "nodeId": "start", "fieldName": "userName", "fieldIndex": 1 }
  ],
  "targetNodeId": "process1",
  "targetFieldName": "userInfo",
  "separator": " "
}
```

### 수정된 파일:

**src/components/MappingEditorModal.tsx**

1. 새로운 인터페이스 추가:
   ```typescript
   export interface SourceField {
     nodeId: string;
     fieldName: string;
     fieldIndex?: number;
   }
   ```

2. MappingConnection 인터페이스 변경:
   - `sourceNodeId`, `sourceFieldName`, `sourceFieldIndex` 제거
   - `sources: SourceField[]` 배열로 변경
   - `separator?: string` 옵션 추가

3. handleDrop 함수 수정:
   - 같은 타겟 필드에 드롭 시 기존 매핑의 sources 배열에 추가
   - 새 타겟 필드에 드롭 시 새 매핑 생성 (sources 배열 1개로 시작)

4. getConnectionLines 함수 수정:
   - sources 배열 순회하며 각 소스에 대해 연결선 생성
   - 다중 소스 매핑 시 여러 선이 같은 타겟으로 연결

5. isMapped 체크 로직 수정:
   - `m.sources.some(s => s.nodeId === ... && s.fieldName === ...)`

6. 매핑 목록 UI 수정:
   - 다중 소스 표시: `start.userId + start.userName`
   - "Concat" 배지 표시

**docs/test-import-flow.json**

- 새로운 sources 배열 형식으로 변환
- 다중 소스 매핑 예시 추가 (map3)

### 사용 방법:
1. 소스 필드를 타겟 필드로 드래그하여 첫 번째 매핑 생성
2. 같은 타겟 필드에 다른 소스 필드를 드래그하면 sources 배열에 추가
3. 드래그한 순서대로 값이 연결됨

### 결과 예시:
```
start.ERR_CD + start.ERR_MSG → process1.errorInfo
```
