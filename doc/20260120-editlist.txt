## 1. Concat 매핑 소스 순서 변경 기능

다중 소스(Concat) 매핑에서 소스 필드의 순서를 변경할 수 있는 기능 추가

### 수정된 파일:

**src/components/MappingEditorModal.tsx**

1. import 추가:
   - `ArrowUp`, `ArrowDown` 아이콘 추가

2. 새로운 함수 추가:
   ```typescript
   // 소스 순서 변경 함수 (위로)
   const moveSourceUp = (mappingId: string, sourceIndex: number) => {
     if (sourceIndex <= 0) return; // 이미 맨 위
     setMappings(prev => prev.map(m => {
       if (m.id === mappingId && m.sources && m.sources.length > 1) {
         const newSources = [...m.sources];
         // 위 요소와 swap
         [newSources[sourceIndex - 1], newSources[sourceIndex]] = [newSources[sourceIndex], newSources[sourceIndex - 1]];
         return { ...m, sources: newSources };
       }
       return m;
     }));
   };

   // 소스 순서 변경 함수 (아래로)
   const moveSourceDown = (mappingId: string, sourceIndex: number) => {
     setMappings(prev => prev.map(m => {
       if (m.id === mappingId && m.sources && sourceIndex < m.sources.length - 1) {
         const newSources = [...m.sources];
         // 아래 요소와 swap
         [newSources[sourceIndex], newSources[sourceIndex + 1]] = [newSources[sourceIndex + 1], newSources[sourceIndex]];
         return { ...m, sources: newSources };
       }
       return m;
     }));
   };

   // 소스 삭제 함수 (다중 소스 매핑에서 개별 소스 삭제)
   const removeSource = (mappingId: string, sourceIndex: number) => {
     setMappings(prev => prev.map(m => {
       if (m.id === mappingId && m.sources) {
         const newSources = m.sources.filter((_, idx) => idx !== sourceIndex);
         // 소스가 0개가 되면 매핑 자체를 삭제
         if (newSources.length === 0) {
           return null as any;
         }
         return { ...m, sources: newSources };
       }
       return m;
     }).filter(Boolean));
   };
   ```

3. 매핑 목록 UI 수정:
   - 다중 소스 매핑일 때 각 소스별로 개별 UI 표시
   - 순서 번호 표시 (1, 2, 3...)
   - 위로 이동 버튼 (ArrowUp 아이콘)
   - 아래로 이동 버튼 (ArrowDown 아이콘)
   - 개별 소스 삭제 버튼 (X 아이콘)
   - 각 소스 사이에 + 구분자 표시
   - 단일 소스 매핑은 기존 방식 유지

### UI 예시:
```
다중 소스 매핑:
+-----------------------------------------------+
| [1] start.ERR_CD  [↑][↓][X] + [2] start.ERR_MSG [↑][↓][X]  Concat → target.field |
+-----------------------------------------------+

단일 소스 매핑:
+-----------------------------------------------+
| start.userId → target.userId                   |
+-----------------------------------------------+
```

### 사용 방법:
1. Concat 매핑이 있는 매핑 목록에서 해당 항목 확인
2. 각 소스 옆의 ↑ 버튼으로 순서를 위로 이동
3. 각 소스 옆의 ↓ 버튼으로 순서를 아래로 이동
4. X 버튼으로 개별 소스 삭제 가능

### 버튼 상태:
- 맨 위 소스: ↑ 버튼 비활성화 (회색)
- 맨 아래 소스: ↓ 버튼 비활성화 (회색)
- 호버 시: 버튼 색상 파란색으로 변경

## 2. 매핑 목록 클릭 시 소스/타겟 노드 자동 변경 기능

매핑 목록에서 항목을 클릭했을 때, 해당 매핑의 소스 노드와 타겟 노드가 현재 선택된 노드와 다르면 자동으로 변경하여 연결선이 화면에 표시되도록 수정

### 수정된 파일:

**src/components/MappingEditorModal.tsx**

1. 매핑 목록 항목 클릭 핸들러 수정 (1371-1393 라인):
   - 기존: `onClick={() => setSelectedMappingId(isSelectedMapping ? null : m.id)}`
   - 수정 후: `handleMappingClick` 함수로 변경

2. 새로운 핸들러 함수 추가:
   ```typescript
   // 매핑 클릭 시 해당 소스/타겟 노드로 변경하는 핸들러
   const handleMappingClick = () => {
     if (isSelectedMapping) {
       // 이미 선택된 매핑을 다시 클릭하면 선택 해제
       setSelectedMappingId(null);
     } else {
       // 새로운 매핑 선택
       setSelectedMappingId(m.id);

       // 클릭한 매핑의 소스 노드로 변경 (현재 선택과 다른 경우)
       const firstSource = sources[0];
       if (firstSource && firstSource.nodeId !== sourceNodeId) {
         setSourceNodeId(firstSource.nodeId);
         sourceFieldRefs.current.clear();
       }

       // 클릭한 매핑의 타겟 노드로 변경 (현재 선택과 다른 경우)
       if (m.targetNodeId !== targetNodeId) {
         setTargetNodeId(m.targetNodeId);
         targetFieldRefs.current.clear();
       }
     }
   };
   ```

### 동작 방식:
1. 매핑 목록에서 항목 클릭
2. 해당 매핑의 첫 번째 소스 노드가 현재 선택된 소스 노드와 다르면 → 소스 드롭다운 자동 변경
3. 해당 매핑의 타겟 노드가 현재 선택된 타겟 노드와 다르면 → 타겟 드롭다운 자동 변경
4. 해당 매핑이 선택됨 (하이라이트 표시)
5. 연결선이 화면에 표시됨

### 사용 예시:
- 소스 노드 A, 타겟 노드 B가 선택된 상태
- 매핑 목록에서 "소스 노드 C → 타겟 노드 D" 매핑 클릭
- 자동으로 소스 노드 C, 타겟 노드 D로 변경됨
- 해당 매핑의 연결선이 화면에 표시됨

3. handleMappingClick에서 노드 변경 전 플래그 설정 (1393-1396 라인)

```typescript

// useEffect 수정

  isNodeChangeFromMappingClick.current = false; // 플래그 리셋
```
