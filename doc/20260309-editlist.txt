# 2026-03-09 수정사항

## 1. IDOSearchModal - 검색 필터 / 버튼 / 그리드 개선

### 수정된 파일
1. **src/components/IDOSearchModal.tsx**

### 변경 내용

#### 1-1. 검색 필터 한글화 및 불필요 항목 삭제
- **한글화**: componentType → "타입", componentId → "컴포넌트 ID", compName → "컴포넌트명"
- **삭제된 필드**: package, packagePath, className, modifier (state 및 UI 모두 제거)
- **타입 기본값**: "타입 선택" 옵션 제거, IDO가 기본 선택되도록 변경
- Enter 키로 검색 가능하도록 `onKeyDown` 핸들러 추가

#### 1-2. 버튼 정리
- "적용" 버튼 삭제 (handleApply → handleApplyAndClose로 변경)
- "적용 및 닫기" 버튼만 유지

#### 1-3. 모달 재오픈 시 상태 초기화
- `useEffect(isOpen)` 에서 모달 열릴 때 `setSelectedItems([])` + `gridRef.current.api.deselectAll()` 호출
- 버튼 비활성화 상태 및 그리드 하단 "선택됨" 문구 자동 초기화

#### 1-4. 그리드 단일 선택 (라디오 버튼)
- `rowSelection.mode`: 'multiRow' → 'singleRow'
- `headerCheckbox`: true → false
- 그리드 컬럼에서 '패키지', '클래스명' 컬럼 삭제
- '컴포넌트 ID' 컬럼: `flex: 1, minWidth: 200`으로 확대

### 미해결 이슈
- **IMO 타입 조회 불일치**: 컴포넌트 검색 모달에서 IMO 조회 결과가 IMO관리 화면과 일치하지 않음
  - 프론트엔드는 `flow_comp_r001.jct` API를 호출하며, 이는 백엔드 서비스 로직 수정 필요
  - IMO관리 화면은 `BIZ_IMO` 대상서버로 조회하는 별도 API 사용
