## 3. Mapping 노드 다중 필드 연결(MultiConcat) 기능 구현

여러 소스 필드와 텍스트를 결합하여 하나의 타겟 필드에 매핑하는 기능

### 사용 시나리오:
- Field1 + Field2 + "1234" → TargetField
- 여러 필드 값을 순서대로 결합
- 필드 사이에 고정 텍스트 삽입 가능

### 수정된 파일:

   - multiConcatMappings 상태 추가
   - MultiConcat 편집 모드 상태들 추가 (isMultiConcatMode, editingMultiConcatId 등)
   - MultiConcat 관련 함수 추가:
     - startNewMultiConcat(): 새 다중 연결 시작
     - cancelMultiConcat(): 편집 취소
     - addMultiConcatSourceField(): 필드 소스 추가
     - addMultiConcatSourceText(): 텍스트 소스 추가
     - updateMultiConcatSourceText(): 텍스트 수정
     - removeMultiConcatSource(): 소스 항목 삭제
     - moveMultiConcatSource(): 소스 순서 변경 (위/아래)
     - saveMultiConcat(): 다중 연결 저장
     - editMultiConcat(): 기존 다중 연결 편집
     - removeMultiConcat(): 다중 연결 삭제
   - MultiConcat Section UI 추가:
