   - `addNode` 함수에 `defaultInternalNodesPreview` 추가

```typescript

  { id: `${id}-start`, type: 'Start', label: 'Start', position: { x: (containerWidth - 180) / 2, y: 100 } },
```

## 6. MappingEditorModal 변환 함수(Transform) 기능 추가

매핑 연결에 substring, toUpperCase, toLowerCase, trim, replace, concat 등 문자열 변환 함수를 적용할 수 있는 기능 추가

### 수정된 파일:

1. **src/components/MappingEditorModal.tsx**
   - `TransformType` 타입 정의: `'none' | 'substring' | 'toUpperCase' | 'toLowerCase' | 'trim' | 'replace' | 'concat' | 'split'`
   - `TransformConfig` 인터페이스 추가 (type, params 포함)
   - `MappingConnection` 인터페이스에 `transform?: TransformConfig` 필드 추가
   - `editingTransformId` 상태 추가 (변환 편집 중인 매핑 추적)
   - `getTransformLabel()` 함수 추가 (변환 타입 표시 이름)
   - `updateMappingTransform()` 함수 추가 (변환 설정 업데이트)
   - 매핑 목록 UI에 변환 버튼 및 편집 패널 추가
   - Wand2, Settings2 아이콘 import

### 지원하는 변환 함수:
| 타입 | 설명 | 파라미터 |
|------|------|----------|
| none | 없음 | - |
| substring | 부분 문자열 추출 | start, end |
| toUpperCase | 대문자 변환 | - |
| toLowerCase | 소문자 변환 | - |
| trim | 공백 제거 | - |
| replace | 문자열 치환 | from, to |
| concat | 문자열 연결 | prefix, suffix |

### UI 동작:
- 각 매핑 항목에 "변환" 버튼 표시
- 클릭 시 변환 함수 선택 패널 확장
- 변환 타입 선택 버튼들 (none, substring, toUpperCase, ...)
- 파라미터 입력 필드 (substring: start/end, replace: from/to, concat: prefix/suffix)
- 적용된 변환은 매핑 라인에 보라색 배지로 표시

### 예시 표시:
- `node1.output.name` → **[Substring(0, 3)]** → `node2.input.shortName`
- `node1.output.email` → **[대문자]** → `node2.input.EMAIL`

## 7. MappingEditorModal - 소스에 Start 노드, 타겟에 End 노드 표시

매핑 에디터에서 소스 노드 목록에 Start 노드가, 타겟 노드 목록에 End 노드가 표시되도록 수정

### 수정된 파일:

1. **src/App.tsx**
   - `availableNodes` 필터에서 `isStart`/`isEnd` 조건 제거
   - Start/End 노드가 MappingEditorModal의 availableNodes에 포함되도록 함

2. **src/components/MappingEditorModal.tsx**
   - `startNode`, `endNode` 변수 추가 (availableNodes에서 Start/End 타입 노드 찾기)
   - `sourceNodeCandidates`: upstream 노드 + Start 노드 추가
   - `targetNodeCandidates`: upstream 노드 + End 노드 추가
   - `nodesWithOutputs`: Start 노드가 항상 첫 번째에 표시되도록 정렬
   - `nodesWithInputs`: End 노드가 항상 첫 번째에 표시되도록 정렬

3. **src/components/ContainerFlowModal.tsx**
   - `currentContainerNodes`에서 start/end 노드 필터 제거
   - Start/End 노드에 올바른 type 속성 지정 (`'Start'`, `'End'`)

### 동작 방식:
- 소스 노드 드롭다운: Start 노드가 첫 번째로 표시됨 (워크플로우 입력 데이터)
- 타겟 노드 드롭다운: End 노드가 첫 번째로 표시됨 (워크플로우 출력 데이터)
- Start 노드의 outputs를 소스로, End 노드의 inputs를 타겟으로 매핑 가능
